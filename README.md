# Minecraft AI 建造助手（minecraft-ai）

一个 Fabric 模组：在游戏里用一句话描述你的想法，AI 帮你设计楼层蓝图，程序自动生成 3D 建筑，预览确认后一键建造，随时可撤销。

## 功能特性

- **一句话生成建筑**：输入"在河边建一座两层中式小楼，带院子"，AI 会画出每层的字符蓝图（墙、窗、门、楼梯、家具、屋顶装饰）
- **程序化 3D 生成**：蓝图自动翻译为真正的 3D 建筑——楼板、层高、窗户、门（上下两格）、床（头尾两格）、家具、台阶、屋顶（平顶/尖顶/女儿墙）全部自动处理
- **3D 预览**：生成后先在游戏内预览整个建筑，满意再建造
- **一键建造 / 撤销**：按完整方案批量放置方块，支持一键撤销整栋建筑
- **空间约束**：可指定建造终点坐标限制范围；超出时给出提示，确认后按完整方案放置
- **游戏内配置界面**：不用改文件，在游戏里切换 AI 后端（OpenAI 兼容接口 / 本地 Ollama）、填写 API 地址与密钥、开关思考模式，保存立即生效
- **可配置层高**：AI 可根据描述自主决定每层层高（2~8 格）

## 环境要求

| 依赖 | 版本 |
| --- | --- |
| Minecraft | 26.1.2 |
| Fabric Loader | >= 0.19.0 |
| Fabric API | 0.155.2+26.1.2 |
| Java | >= 24 |

## 安装方法

1. 安装 [Fabric Loader](https://fabricmc.net/use/) 与 Minecraft 26.1.2
2. 将 `fabric-api` 与 `minecraft-ai-1.0.0.jar` 放入 `.minecraft/versions/<版本>/mods/` 目录
3. 启动游戏

## 使用方法

1. 在游戏中按 **K** 键打开"AI 建造助手"面板
2. 输入建筑描述（一句话即可），设置起点坐标 X / Y / Z（默认玩家面前 10 格）；终点坐标可留空（不限空间）
3. 点击「生成方案」，等待 AI 回复（约 10~90 秒，取决于后端）
4. 在右侧预览 3D 建筑，确认无误后点击「确认建造」
5. 想反悔？点击「撤销上次」一键拆除

状态栏会显示生成进度、超空间提示与建造结果；文字过长时可鼠标滚轮滚动查看。

## AI 后端配置

点击面板右下角「设置」打开配置界面：

- **后端类型**：`OpenAI 兼容`（默认，支持任何 OpenAI 格式的 API，如 DeepSeek、Moonshot、智谱等）或 `本地 Ollama`
- **API 地址 / 模型名 / API Key**：OpenAI 兼容接口必填
- **Ollama 地址 / 模型**：使用本地 Ollama 时填写（默认 `http://localhost:11434`）
- **思考模式**：开关 AI 思考（chain-of-thought），不支持的供应商可关闭
- 保存后立即生效，无需重启游戏

示例：使用 DeepSeek 时，API 地址填 `https://api.deepseek.com/v1`，模型填 `deepseek-chat`；使用本地 Ollama 时模型需已 `ollama pull` 下载。

> 注意：生成建筑需要联网调用 AI 接口（或本地 Ollama），未配置后端时面板会提示不可达。

## 建筑方案说明

AI 以"模板制"输出方案，通常包含三张图：

- **首层蓝图**（`1`）：一层的地面布置，含大门 `D`、窗户 `W`、家具
- **普通层蓝图**（`2`~`N-1`）：标准楼层样式
- **顶层蓝图**（`top`）：顶层布局，可额外多画一行作为屋顶装饰（避雷针、天灯等）

常用字符：`#` 墙、`W` 窗、`D` 门、`P` 柱、`S` 楼梯井、`R` 床、`B` 书柜、`C` 工作台、`F` 熔炉、`L` 灯笼、`T` 花盆、`X` 海晶灯、`.` 空地。

AI 会根据描述自主决定层数（`floors`）、每层层高（`layer_height`，2~8）、墙体材质（`wall`）、点缀材质（`accent`）与屋顶样式（`roof`：`flat` 平顶 / `pyramid` 尖顶 / `gabled` 人字顶）。

## 已知限制

- 目前仅支持单人游戏（多人服务器需要服务端支持）
- AI 输出偶尔会被截断导致解析失败，点「生成方案」重试即可
- 建筑体积较大（数万方块）时建造耗时数秒，期间请勿关闭游戏
