# Minecraft AI 建造助手（minecraft-ai）

一个 Fabric 模组：在游戏里用一句话描述你的想法，AI 帮你设计楼层蓝图，程序自动生成 3D 建筑，预览确认后一键建造，随时可撤销。支持对方案持续提意见迭代调整，生成过程后台运行不耽误你玩游戏。

## 功能特性

- **一句话生成建筑**：输入"在河边建一座两层中式小楼，带院子"，AI 会画出每层的字符蓝图（墙、窗、门、楼梯、家具、屋顶装饰）
- **程序化 3D 生成**：蓝图自动翻译为真正的 3D 建筑——楼板、层高、窗户、门（上下两格）、床（头尾两格）、家具、台阶、屋顶（平顶/尖顶/女儿墙）全部自动处理
- **可交互 3D 预览**：滚轮缩放、右键拖拽无级旋转（水平/俯仰/任意斜向）、左键拖拽平移、双击复位；大型建筑自动缩放到预览区，整体轮廓一目了然
- **后台生成 + 悬浮球**：生成期间可关闭界面继续玩游戏，屏幕右上角 MC 像素风悬浮球实时显示进度秒数；生成完成或失败会变色提示，按 K 即可查看结果，绝不因误触而中断
- **方案迭代调整**：对 AI 的方案追加意见（如"三层改成露台，窗户多一倍"），AI 在自己的方案基础上修改输出新方案；建造完成后仍可继续调整，确认建造时自动替换旧建筑
- **一键建造 / 撤销**：按完整方案批量放置方块，支持一键撤销整栋建筑
- **空间约束**：可指定建造终点坐标限制范围；超出时给出提示，确认后按完整方案放置
- **游戏内配置界面**：不用改文件，在游戏里切换 AI 后端（OpenAI 兼容接口 / 本地 Ollama）、填写 API 地址与密钥、开关思考模式，保存立即生效
- **可配置层高**：AI 可根据描述自主决定每层层高（2~8 格）

## 环境要求

| 依赖 | 版本 |
| --- | --- |
| Minecraft | 26.1.2 |
| Fabric Loader | >= 0.19.0 |
| Fabric API | 0.155.2+26.1.2 |
| Java | >= 24 |

## 安装方法

1. 安装 [Fabric Loader](https://fabricmc.net/use/) 与 Minecraft 26.1.2
2. 从 [Releases](https://github.com/xhmzlzg/minecraft-ai-builder/releases) 下载最新版模组 jar，与 `fabric-api` 一起放入 `.minecraft/versions/<版本>/mods/` 目录
3. 启动游戏

## 使用方法

1. 在游戏中按 **K** 键打开"AI 建造助手"面板
2. 输入建筑描述（一句话即可），设置起点坐标 X / Y / Z（默认玩家面前 10 格）；终点坐标可留空（不限空间）
3. 点击「生成方案」，等待 AI 回复（约 10~90 秒，取决于后端）；期间可按 ESC 关闭面板继续游玩，右上角悬浮球会显示进度
4. 生成完成后按 K 打开面板（或看悬浮球提示），在预览区用滚轮缩放、右键拖拽旋转检查建筑
5. 满意后点击「确认建造」；想反悔？点击「撤销上次」一键拆除

### 迭代调整方案

- 点击「调整上次方案」：自动载入上一次的方案与坐标（3D 预览同步显示）
- 在输入框写下要调整的内容（如"三层改成露台，窗户多一倍"），点击「确认调整」
- AI 会保留原设计的其余部分，只改你要求的地方，输出新方案供预览
- 建造完成后仍可继续调整；对调整后的方案点「确认建造」会**自动撤销旧建筑并重建**（替换）

> 提示：「生成方案」永远是全新设计；「调整上次方案」才基于历史方案修改。

## AI 后端配置

点击面板右下角「设置」打开配置界面：

- **后端类型**：`OpenAI 兼容`（默认，支持任何 OpenAI 格式的 API，如 DeepSeek、Moonshot、智谱等）或 `本地 Ollama`
- **Base URL / 模型名 / API Key**：OpenAI 兼容接口必填
- **Ollama 地址 / 模型**：使用本地 Ollama 时填写（默认 `http://127.0.0.1:11434`）
- **思考模式**：开关 AI 思考（chain-of-thought），不支持的供应商可关闭
- 保存后立即生效，无需重启游戏

示例：使用 DeepSeek 时，Base URL 填 `https://api.deepseek.com/v1`，模型名填 `deepseek-chat`；使用本地 Ollama 时模型需已 `ollama pull` 下载。

> 注意：生成建筑需要联网调用 AI 接口（或本地 Ollama），未配置后端时面板会提示不可达。API Key 仅保存在你本地的配置文件中，不会上传。

## 建筑方案说明

AI 以"模板制"输出方案，通常包含三张图：

- **首层蓝图**（`1`）：一层的地面布置，含大门 `D`、窗户 `W`、家具
- **普通层蓝图**（`2`~`N-1`）：标准楼层样式
- **顶层蓝图**（`top`）：顶层布局，可额外多画一行作为屋顶装饰（避雷针、天灯等）

常用字符：`#` 墙、`W` 窗、`D` 门、`P` 柱、`S` 楼梯井、`R` 床、`B` 书柜、`C` 工作台、`F` 熔炉、`L` 灯笼、`T` 花盆、`X` 海晶灯、`.` 空地。

AI 会根据描述自主决定层数（`floors`）、每层层高（`layer_height`，2~8）、墙体材质（`wall`）、点缀材质（`accent`）与屋顶样式（`roof`：`flat` 平顶 / `pyramid` 尖顶 / `gabled` 人字顶）。

## 已知限制

- 目前仅支持单人游戏（多人服务器需要服务器端支持）
- AI 输出偶尔会被截断导致解析失败，点「生成方案」重试即可
- 建筑体积较大（数万方块）时建造耗时数秒，期间请勿关闭游戏
- 游戏内鼠标被游戏视角捕获时无法点击悬浮球，请按 K 查看生成结果
